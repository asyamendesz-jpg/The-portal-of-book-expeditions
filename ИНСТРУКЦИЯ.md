# Портал книжных экспедиций — инструкция

## Как открыть сайт

1. Откройте папку проекта на компьютере.
2. Запустите **локальный сервер** (без него PDF могут не скачиваться):

```powershell
cd "путь\к\папке\внеклассное чтение"
py -m http.server 8080
```

3. В браузере перейдите по адресу: **http://localhost:8080**

> Не открывайте `index.html` двойным щелчком (`file://`) — ссылки на PDF работают только через сервер.

На GitHub Pages сайт доступен по адресу репозитория проекта.

## Маршрут экспедиции для ребёнка (v1.0)

1. **Главная** → «Начать экспедицию»
2. **Книжные путешествия** → «Приключения Алисы»
3. **Начать путешествие** → послушать эпизод
4. **Познакомься с героями** → начать испытание
5. **Узнай героя по описанию** → собрать карточку
6. **Собери карточку** → полевое задание
7. **Полевое задание** → дневник
8. **Дневник** → достижения
9. **Достижения** → финал (по желанию — комиксы)

PDF-комплекты и страница `trial-tasks.html` — дополнительные материалы, не обязательны для прохождения.

## Где хранятся данные

| Массив | Файл | Что добавлять |
|--------|------|---------------|
| `books[]` | `js/data/books.js` | Новые книги-экспедиции |
| `chapters[]` | `js/data/chapters.js` | Главы карты путешествия |
| `heroes[]` | `js/data/heroes.js` | Герои книг |
| `cards[]` | `js/data/cards.js` | Карточки персонажей |
| `workbooks[]` | `js/data/workbooks.js` | PDF-комплекты |
| `quizzes[]` | `js/data/quizzes.js` | Викторины (поле `stars` — сложность) |
| `passports[]` | `js/data/passports.js` | Паспорта |
| `comics[]` | `js/data/comics.js` | Комиксы читателей |
| `pages[]`, `banners` | `js/data/pages.js` | Меню и баннеры |

HTML менять **не нужно** — достаточно дописать объект в нужный массив.

## Как добавить новую книгу

Откройте `js/data/books.js` и добавьте объект:

```javascript
{
  id: 'new-book-id',
  title: 'Название книги',
  author: 'Автор',
  route: 'Тематика маршрута',
  color: '#4a7cb8',
  cover: 'images/covers/new-book.png'
}
```

Положите обложку в `images/covers/`.

---

## Как добавить героя

1. Добавьте портрет в `images/heroes/` (лучше лёгкий `.jpg`).
2. Откройте `js/data/heroes.js`:

```javascript
{
  id: 'hero-id',
  name: 'Имя героя',
  role: 'Роль',
  description: 'Краткое описание.',
  bookId: 'alice-journey',
  image: 'images/heroes/hero-id.jpg',
  color: '#e87461'
}
```

3. При необходимости добавьте карточку в `js/data/cards.js` с тем же `bookId` и `heroId`.

---

## Как добавить PDF-комплект

1. Положите файл в папку `pdf/`.
2. Добавьте запись в `js/data/workbooks.js`:

```javascript
{
  id: 'kit-new',
  title: 'Название комплекта',
  description: 'Описание.',
  bookId: 'alice-journey',
  file: 'pdf/имя-файла.pdf'
}
```

---

## Как заменить баннер страницы

1. Положите изображение в `images/mockups/` с понятным именем:
   - `home.png`, `expedition-start.png`, `book-travel.png`
   - `heroes.png`, `cards.png`, `quiz.png`, `comics.png`
2. Обновите путь в `js/data/pages.js` → объект `banners`:

```javascript
heroes: {
  image: 'images/mockups/heroes.png',
  alt: 'Описание для доступности',
  title: 'Герои книг',
  intro: 'Текст под баннером.'
}
```

Главная страница использует баннер напрямую в `index.html` (`images/mockups/home.png`).

## Советы

- Используйте **короткие латинские имена** для файлов изображений (`alice.jpg`, без пробелов).
- После изменения данных обновите страницу в браузере (Ctrl+F5).
- Админка автора: `/admin/` — нужна настройка Supabase (см. `js/data/analytics-config.js`).
